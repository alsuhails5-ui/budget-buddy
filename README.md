# Budget Buddy — React Budgeting Application

A responsive personal expense tracker built with React and Vite.

## Features
- Set a monthly budget and view remaining balance
- Add expenses with title, amount, category and date
- Search transactions and delete expenses
- Category-wise spending snapshot
- Responsive layout for desktop and mobile
- Browser localStorage persistence (no backend/account required)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Push this repository to GitHub, then import it into Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.
